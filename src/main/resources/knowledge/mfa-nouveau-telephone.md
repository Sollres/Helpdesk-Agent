# Configurer l'authentification multifacteur (MFA) sur un nouveau téléphone

L'authentification multifacteur utilise l'application Microsoft Authenticator. Elle est demandée pour Microsoft 365, le VPN et le portail MonCompte.

## Changement de téléphone (ancien téléphone encore disponible)

1. Sur le nouveau téléphone, installez Microsoft Authenticator.
2. Sur un ordinateur, ouvrez https://mysignins.microsoft.com/security-info.
3. Cliquez sur « Ajouter une méthode de connexion » puis « Application Authenticator ».
4. Scannez le QR code affiché avec le nouveau téléphone.
5. Validez la notification de test, puis supprimez l'ancien téléphone de la liste.

## Téléphone perdu, volé ou réinitialisé

Sans l'ancien téléphone, vous ne pouvez pas ajouter de méthode vous-même. Créez un ticket avec la priorité haute (ou appelez le support au poste 4357) : après vérification de votre identité, le support réinitialise votre MFA et vous pourrez enregistrer le nouveau téléphone. En cas de vol, signalez-le aussi comme incident de sécurité.

## Les notifications n'arrivent pas

- Vérifiez que les notifications de l'application Authenticator sont autorisées sur le téléphone.
- Vérifiez que l'heure du téléphone est en mode automatique.
- En attendant, utilisez le code à 6 chiffres affiché dans l'application : choisissez « Je ne peux pas utiliser mon application » puis « Utiliser un code de vérification ».
