# Signaler un e-mail suspect (phishing)

## Reconnaître un e-mail suspect

- Expéditeur inconnu ou adresse qui imite une adresse connue (ex. « entrepr1se.com »).
- Message urgent ou menaçant : « votre compte sera supprimé », « facture impayée ».
- Lien dont l'adresse réelle (survolez-le sans cliquer) ne correspond pas au site annoncé.
- Demande de mot de passe, de code MFA ou de coordonnées bancaires. Le support informatique ne demande jamais votre mot de passe.

## Signaler le message

1. Dans Outlook, sélectionnez le message sans l'ouvrir si possible.
2. Cliquez sur le bouton « Signaler » dans le ruban, puis « Hameçonnage ».
3. Le message est transmis à l'équipe sécurité et retiré de votre boîte.

## J'ai cliqué sur le lien ou saisi mon mot de passe

Agissez immédiatement :
1. Changez votre mot de passe depuis le portail MonCompte (https://moncompte.intranet.local).
2. Appelez le support au poste 4357, ou créez un ticket avec la priorité critique, en précisant l'heure et ce que vous avez saisi.
3. Si vous avez ouvert une pièce jointe, débranchez le câble réseau et désactivez le Wi-Fi du poste, puis prévenez le support.

Il n'y a aucune sanction pour une erreur signalée rapidement : plus le signalement est rapide, plus les dégâts sont limités.
