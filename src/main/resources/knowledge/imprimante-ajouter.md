# Ajouter une imprimante et imprimer

Les imprimantes des bureaux utilisent l'impression sécurisée : le document est libéré seulement quand vous badgez sur l'imprimante.

## Ajouter l'imprimante sécurisée

1. Le poste doit être au bureau ou connecté au VPN.
2. Ouvrez le menu Démarrer et tapez « \\print.entreprise.local », puis Entrée.
3. Double-cliquez sur la file « Impression-Securisee ». Le pilote s'installe automatiquement.
4. Imprimez sur « Impression-Securisee », puis badgez sur n'importe quel copieur de l'entreprise pour récupérer le document.

Les documents non récupérés sont supprimés après 24 heures.

## L'imprimante n'apparaît pas

1. Vérifiez la connexion au réseau de l'entreprise (Wi-Fi Corp-WiFi, câble ou VPN). Depuis le Wi-Fi Guest, l'impression est impossible.
2. Redémarrez le poste puis recommencez l'ajout.

## Le badge n'est pas reconnu sur le copieur

À la première utilisation, le copieur demande d'associer le badge : saisissez votre identifiant Windows et votre mot de passe sur l'écran du copieur. Si le badge est neuf ou a été remplacé, faites de même.

## Bourrage, toner vide, copieur en panne

Ce n'est pas un problème de poste : signalez-le par un ticket de catégorie matériel, en indiquant l'étage et le numéro inscrit sur l'étiquette du copieur.
